# UI/UX Pro Max Skill

## Purpose
Perform a senior-level UI/UX design pass that turns functional screens into polished, modern, accessible, responsive product experiences with strong hierarchy, workflow clarity, and real-world usability.

## When To Use It
Use when a website, app, dashboard, form flow, landing page, mobile screen, or SaaS interface needs a deeper design upgrade than ordinary polish. This is the right skill for "make it beautiful", "make it client-ready", "make it feel premium", "redesign this screen", or "professional UI/UX pass".

## Checklist
- Inspect the current product, audience, business goal, primary workflow, and existing design patterns.
- Identify the screen's job: what users should understand, decide, and do first.
- Strengthen information architecture, hierarchy, grouping, navigation, and call-to-action priority.
- Improve visual design: spacing, alignment, typography scale, color balance, contrast, density, border radius, shadows, and icon usage.
- Improve interaction design: hover, focus, active, pressed, disabled, loading, empty, error, success, and confirmation states.
- Improve responsive behavior across mobile, tablet, laptop, and wide desktop.
- Verify accessibility: semantic structure, labels, keyboard flow, focus visibility, color contrast, reduced motion, and target sizes.
- Make copy clearer, more specific, and more useful without adding filler.
- Keep components maintainable and consistent with the existing framework or design system.
- Run available build, lint, typecheck, tests, and visual smoke checks.

## Rules
- Build the actual usable screen first; do not replace product work with decorative marketing filler.
- Match the design style to the product category. Operational tools should be calm, dense, and scannable; consumer apps can be more expressive.
- Do not use one-note palettes, random gradients, oversized hero treatments, nested cards, or decorative blobs as a shortcut for design.
- Prefer purposeful icons and familiar controls over text-heavy tool buttons.
- Keep text readable and contained at every viewport size.
- Preserve existing user intent and data flows unless redesigning them is clearly required.
- Treat accessibility, responsiveness, empty/error states, and copy quality as core design work.

## Output Format
Return:
- Design verdict.
- Highest-impact UX issues found.
- Changes made.
- Files changed.
- Viewports and accessibility checks performed.
- Commands run.
- Remaining design risks or recommended next refinements.

## Common Mistakes To Avoid
- Making a screen prettier but harder to use.
- Designing only for desktop.
- Adding visual effects that do not support comprehension or action.
- Ignoring forms, validation messages, empty states, and loading states.
- Using generic content instead of product-specific copy.
- Breaking consistency with the existing design system.
