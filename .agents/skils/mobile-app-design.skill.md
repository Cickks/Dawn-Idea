# Mobile App Design Skill

## Purpose
Design and review mobile app experiences for modern iOS and Android expectations.

## When To Use It
Use for React Native/Expo, SwiftUI, Kotlin, or mobile-responsive app screens.

## Checklist
- Identify core user task and navigation model.
- Check safe areas, touch targets, spacing, typography, platform conventions, and state handling.
- Design loading, offline, empty, error, and permission states.
- Verify small-screen and large-screen behavior.
- Confirm accessibility labels, dynamic text tolerance, and color contrast.

## Rules
- Favor native-feeling patterns over cramped web layouts.
- Keep tap targets at practical mobile sizes.
- Avoid tiny text, dense controls, and hidden critical actions.

## Output Format
Return screen-level recommendations, implementation changes, device sizes checked, and unresolved risks.

## Common Mistakes To Avoid
- Treating mobile as a narrow desktop page.
- Ignoring keyboard overlap, safe areas, and permission flows.
- Forgetting offline or slow-network states.
