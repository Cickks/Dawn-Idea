# UI/UX Polish Skill

## Purpose
Improve an existing interface so it feels professional, usable, accessible, and visually coherent.

## When To Use It
Use for visual polish passes on websites, dashboards, mobile screens, forms, landing pages, and product flows.

## Checklist
- Inspect current layout, audience, and primary workflow.
- Check hierarchy, spacing, typography, contrast, color, alignment, and responsive behavior.
- Review interactive states: hover, focus, disabled, loading, empty, error, success.
- Verify accessibility basics: labels, keyboard flow, focus visibility, semantic structure, and contrast.
- Implement focused changes and verify at mobile and desktop sizes.

## Rules
- Improve the actual usable screen, not a marketing shell.
- Keep copy concise and useful.
- Avoid decorative clutter that does not support the workflow.
- Preserve the existing design system unless it is clearly broken.

## Output Format
Return summary, changed files, before/after rationale, verification commands/screenshots, and remaining risks.

## Common Mistakes To Avoid
- Only changing colors while ignoring layout and workflow.
- Adding oversized cards, generic gradients, or ornamental sections.
- Forgetting mobile, keyboard, loading, and error states.
