# Website Design Skill

## Purpose
Create or improve professional websites that can represent a real client, product, service, or portfolio.

## When To Use It
Use for marketing sites, business websites, portfolios, service pages, and launch pages.

## Checklist
- Clarify audience, offer, primary action, and trust signals.
- Make the first viewport communicate the brand or subject clearly.
- Build responsive sections with strong hierarchy and readable copy.
- Add real content structure: services/features, proof, process, contact, FAQ when useful.
- Verify performance, accessibility, SEO basics, and mobile layout.

## Rules
- Build the actual website experience, not placeholder filler.
- Use meaningful imagery or product visuals when relevant.
- Keep navigation and calls to action obvious.

## Output Format
Return page structure, changed files, responsive verification, and launch-readiness notes.

## Common Mistakes To Avoid
- Generic hero copy that could fit any company.
- Stock-like visuals that hide the real product or service.
- Desktop-only spacing and unreadable mobile sections.
