# SEO Content Skill

## Purpose
Improve website content, metadata, structure, and discoverability while keeping pages useful, credible, and human.

## When To Use It
Use for business websites, landing pages, service pages, blogs, local SEO, portfolios, product pages, metadata, headings, schema markup, and launch content review.

## Checklist
- Identify audience, search intent, service area, offer, and conversion goal.
- Create clear page titles, meta descriptions, headings, URLs, and internal links.
- Make copy specific, credible, and useful instead of keyword-stuffed.
- Include local/service details, proof, FAQs, and calls to action where relevant.
- Add meaningful alt text for content images.
- Add Open Graph/social metadata and schema markup when useful.
- Check page speed basics, responsive layout, accessibility, and crawlable content.
- Document target keywords and content assumptions.

## Rules
- Write for real users first.
- Do not promise rankings.
- Avoid generic filler and repeated keyword blocks.
- Keep claims accurate and supportable.
- Match SEO work to the business model and page purpose.

## Output Format
Return:
- SEO/content strategy.
- Metadata and heading changes.
- Copy changes.
- Schema/internal-link recommendations.
- Files changed.
- Remaining content gaps.

## Common Mistakes To Avoid
- Keyword stuffing.
- Vague copy that could fit any business.
- Missing local/service intent.
- Forgetting social previews and metadata.
- Hiding important content in images only.
